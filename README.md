# Unit testaus tehtävä

Kirjastosta löytyy tyypillisimpiä matemaattisia operaattoreita hyödyntäviä funktioita, joille suoritetaan yksikkötestit mocha ja chai-kirjastoilla.
- 'mylib.js' kirjasto
- 'main.js' pääohjelma, testimielessä
- 'unit_test/unittest.js' yksikkötestit
